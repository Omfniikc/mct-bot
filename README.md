MCT — персональный ассистент питания в Telegram. Бот распознаёт блюда по
фотографии, голосовому сообщению или тексту с помощью нейросети, считает
калории и макронутриенты, ведёт дневник питания и замеров, строит графики
динамики и не даёт забыть про приём пищи.

## ✨ Возможности

### Дневник питания — тремя способами

| Способ | Как работает |
|---|---|
| 📷 **Фото** | Снимок еды → нейросеть распознаёт блюда, оценивает вес и КБЖУ каждого → красивая карточка с таблицей в ответ |
| 🎤 **Голос** | «Съел двести грамм гречки с куриной котлетой» → распознавание речи → разбор состава и порций |
| ⌨️ **Текст** | Просто напиши, что съел — бот разберёт и посчитает |

- карточка приёма пищи с фото блюда и таблицей КБЖУ генерируется как картинка;
- распознал неправильно? Значения можно **скорректировать** прямо в чате;
- дневная сводка: сколько съедено против нормы, что осталось.

### Контроль прогресса

- 📊 **Дневник замеров** — вес и объёмы, графики динамики за неделю / месяц / квартал;
- 🎯 **Расчёт нормы** калорий и БЖУ по анкете (пол, возраст, рост, вес, активность) и цели (похудение / набор массы);
- ⏰ **Напоминания** о завтраке, обеде и ужине; еженедельные сводки по весу (APScheduler).

### Для тренеров

- привязка клиентов к тренеру, просмотр их дневников и замеров;
- ежедневная статистика по всем клиентам.

### Монетизация и админка

- 💳 **Подписка** через ЮKassa (месяц / 3 месяца), автоплатежи, тестовый режим;
- 🛠 **Админ-панель**: управление пользователями и подписками, загрузка/выгрузка БД, SQL-запросы, реферальная статистика.

## 🚀 Быстрый старт

### 1. Зависимости

Нужен [uv](https://docs.astral.sh/uv/) (менеджер окружений Python):

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

```bash
git clone https://github.com/omniikc/mct-bot.git
cd mct-bot
uv sync
```

### 2. Браузер для Playwright

Таблицы КБЖУ рендерятся из HTML в PNG — нужен Chromium:

```bash
uv run playwright install chromium
```

### 3. Конфигурация

```bash
cp .env.example .env
```

| Переменная | Обязательная | Где взять |
|---|:---:|---|
| `TG_TOKEN` | ✅ | [@BotFather](https://t.me/BotFather) — `/newbot` |
| `ADMIN_ID` | ✅ | [@userinfobot](https://t.me/userinfobot) |
| `TOKIFY_API_KEY` | ✅ | кабинет провайдера нейросети |
| `SHOP_ID` | — | [ЮKassa](https://yookassa.ru) → Настройки |
| `PAY_TOKEN` | — | ЮKassa → API-ключи (`test_...` для тестов, деньги не списываются) |
| `PROXY_URL` | — | SOCKS5/HTTP-прокси для Telegram; пусто = напрямую |
| `POLING` | — | `true` — polling (по умолчанию), `false` — webhook |

### 4. Запуск

```bash
uv run bot.py
```

Для webhook-режима задай `POLING=false` и заполни `WEBHOOK_HOST` / `WEBHOOK_PATH`,
затем подними любой HTTPS-прокси перед `WEBHOOK_PORT`.

## 🗂 Структура проекта

```
bot.py               # точка входа: polling / webhook, регистрация роутеров
config.py            # конфигурация из .env
├─ handlers/         # роутеры aiogram: анкета, питание, замеры, оплата, админка…
├─ middlewares/      # приватный чат, проверка админа, проверка подписки
├─ keyboards/        # inline- и reply-клавиатуры
├─ fsm/              # состояния сценариев (анкета, добавление еды, подписки)
├─ db_methods/       # слой доступа к SQLite (aiosqlite, параметризованные запросы)
├─ gpt_models/       # нейросеть: фото/голос/текст → JSON с блюдами и КБЖУ
├─ generate/         # рендер HTML-таблиц → PNG (Playwright), графики прогресса
├─ text/             # тексты сообщений и HTML-шаблоны таблиц
└─ fonts/            # шрифты для генерации карточек
```

## 📈 Как это выглядит

1. Пользователь отправляет фото тарелки.
2. Бот скачивает картинку, кодирует в base64 и отправляет нейросети.
3. Нейросеть возвращает JSON: список блюд с весом, калориями, белками, жирами, углеводами.
4. Playwright рендерит HTML-шаблон с фото и таблицей в PNG-карточку.
5. Бот присылает карточку и сводку дня: «Съедено 640 из 2100 ккал».
